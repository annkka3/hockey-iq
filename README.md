# Hockey IQ

Тренажёр хоккейного мышления для центрального нападающего 14 лет. Ситуация на льду оживает на полторы секунды и замирает: нужно решить, куда ехать или что делать с шайбой. После ответа приложение проигрывает последствия, показывает лучшее решение и принцип, который за ним стоит.

Отдельное приложение: свой репозиторий, свой проект Firebase, свои ключи хранения (`hk_*`) и кэш (`hk-shell-*`). С языковыми приложениями не пересекается ни аккаунтами, ни данными, даже на одном телефоне.

## Что внутри (v0.4)

- **Сегодня.** Тренировка дня из 10 ситуаций: сначала те, что пора повторить, потом новые. Серия дней, очки, 12 званий, сообщение и цель недели от родителя, принцип дня.
- **Решения — 60 ситуаций.** Колоды «Без шайбы» (24), «С шайбой» (18), «Вбрасывания» (8), «Спецбригады» (10) и «Мои моменты». Режим матча: план «давим» или «от обороны». Карточки с контекстом (план, счёт, конец смены, большинство/меньшинство) учатся отдельно в каждом контексте.
- **Карточка.** Подводка 1,5 с с «призраками», стоп-кадр, ответ кнопкой или нажатием по льду, проигрыш хода, «Показать лучший», принцип.
- **Бросок.** Геометрия: двигаешь себя и вратаря, видишь угол на ворота, долю открытых ворот, время полёта и ворота глазами бросающего; карта открытости ворот по зоне. Игра свайпом, 5 режимов: угол, обыграй вратаря, королевская дорога, смени угол, заслон. Уровни вратаря и сила броска «мой возраст / НХЛ».
- **Реакция.** Память на позиции, слежение за тремя шайбами, предсказание движения, реакция на вбрасывании, блиц-решения на 4 секунды.
- **Я.** Точность по принципам и фазам, время решения, настройки, аккаунт.
- **Для родителей** (PIN): активность, слабые принципы, застрявшие ситуации, ошибки, сообщение, цель недели, редактор «Мои моменты», ревью карточек.

Все встроенные карточки — черновики (`status: draft`) и ждут ревью.

### Физика броска

`js/engine/shot.js`. Точно — геометрия: проекция силуэта вратаря на створ 1,83 × 1,22 м лучами из точки броска, время полёта. Приближённо — параметры: силуэт в стойке и бабочке, реакция вратаря 0,17–0,26 с по уровню, скорость рук и щитков, разброс сильного броска. Механика самого броска не моделируется.

### Карточка

Координаты в метрах: `x` от −15 (левый борт) до 15, `y` от 0 (свой торец) до 60, атака всегда вверх. Ориентиры IIHF: линия ворот 4, синяя 22,86, центр 30, чужая синяя 37,14, чужая линия ворот 56, точки в зоне — `x ±7`, `y 10` и `50`.

```json
{
  "id": "c-oz-04", "version": 1, "deck": "with-puck", "phase": "oz", "principle": "royal-road", "difficulty": 2,
  "title": "Королевская дорога", "view": "oz",
  "question": { "kind": "choice", "text": "…" },
  "us":   [{ "id": "C", "role": "C", "me": true, "x": -7.5, "y": 47, "from": [-9.5, 41] }],
  "them": [{ "id": "g", "role": "G", "x": -0.7, "y": 55.1 }],
  "puck": { "x": -6.9, "y": 46.4, "from": [-8.9, 40.4] },
  "options": [{ "id": "a", "label": "…", "verdict": "best", "explain": "…",
                "moves": [{ "who": "puck", "to": [6, 49], "kind": "pass" }] }],
  "variants": [{ "key": "plan:press", "label": "План: давим", "verdicts": { "a": "best" }, "explain": { "a": "…" } }],
  "source": { "basis": "…" }, "status": "draft"
}
```

`question.kind`: `choice` — кнопки, `tap` — нажатие по льду, у вариантов `zone: {x, y, r}`. `view`: `dz`, `nz`, `oz`, `full` или `[y0, y1]`. Ходы: `skate` (по умолчанию для игрока), `pass`, `shot`; `carry: true` — шайба едет с игроком, `with: true` — одновременно с предыдущим ходом. Контекст: ключи `plan:*`, `score:*`, `strength:*`, `clock:*`.

После правки карточек: `python3 tools/build_content.py` — сборщик проверит лёд, вердикты, зоны и ходы и откажется собирать, если что-то не так.

## Облако (когда понадобится второе устройство или командная версия)

1. [console.firebase.google.com](https://console.firebase.google.com) → новый проект, например `hockey-iq`. Не используйте проект языковых приложений.
2. Build → Authentication → Sign-in method → включить «Email/Password».
3. Build → Firestore Database → создать (регион europe-west); вкладка Rules → вставить содержимое `firestore.rules` → Publish.
4. Project settings → Your apps → Web app → скопировать объект `firebaseConfig` в `config.js` вместо `firebase: null`.
5. Authentication → Settings → Authorized domains → добавить `annkka3.github.io`.

После этого во вкладке «Я» появится вход. Прогресс, накопленный на телефоне до входа, сольётся с облаком.
